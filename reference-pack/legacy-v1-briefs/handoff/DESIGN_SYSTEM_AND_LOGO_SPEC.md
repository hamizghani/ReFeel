# Familiar Design System and Logo Specification

## Visual direction

Use expressive pastel surfaces with a restrained editorial foundation. Core colors are lilac, powder blue, mint, and soft pink. Use deep ink for text, a quiet lavender for active controls, and warm off-white for the main field. Keep contrast readable and never rely on pastel color alone to communicate status.

Use a strong sans-serif interface face paired with an editorial serif or italic accent for selected display words. Maintain generous whitespace, rounded cards, clear hierarchy, restrained borders, and purposeful motion.

## Logo brief

Create a simple but meaningful SVG system:

- primary wordmark: `familiar` in a clear lower-case form;
- compact mark: an abstract relationship between a garment fold, a familiar loop, and an evidence frame;
- the mark must work at favicon size and in monochrome;
- avoid literal hanger or camera clip-art;
- create light and dark variants;
- include accessible title and description metadata;
- include a small construction note in the source file and a brand manifest;
- do not claim trademark clearance.

## Interaction grammar

Role gateways use two large role cards plus Explore both. Capture uses one dominant action, a progress track, concise instructions, a visual frame, and a clear review state. Evidence uses source media, marker, status, and unknowns. Product cards use image, category, size, price, condition cue, and save action. Coming soon cards use a disabled state.
