# V2 sources and standards

## Product and design authority

The user's clarified photo/recording revision and attached DESIGN GUIDELINE take precedence over the older 3D brief. The supplied mobile and desktop Stitch exports inform marketplace, gallery, comparison, studio, review and aftercare compositions. Their fictitious statistics, confidence percentages, sensor claims and inconsistent garment facts are not adopted.

The existing Vercel site was inspected through the requested cloud browser. That is a bounded observation of the previous deployed interface, not verification of the new release.

## Implementation and review references

- [Taste Skill](https://github.com/Leonxlnx/taste-skill): deliberate hierarchy, visual composition and useful interaction detail.
- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines): semantic controls, focus, motion, imagery and responsive interaction review.
- [Awesome Design MD](https://github.com/voltagent/awesome-design-md): design references for discovery and product presentation.
- [Vite on Vercel](https://vercel.com/docs/frameworks/frontend/vite): static Vite deployment and SPA routing.
- [Playwright](https://playwright.dev/docs/intro): reproducible browser interaction checks; the tests use its JavaScript API.
- [WCAG 2.1](https://www.w3.org/TR/WCAG21/): bounded automated A/AA checks using Axe tags; no claim of complete conformance or human certification.

## Evidence and source boundaries

`docs/PHOTO_ASSET_PROVENANCE.md` and `public/photos/manifest.json` link the actual garment image sources. Retail product information is not a specimen-specific label or condition record. Listing measurements and qualitative feel vectors are authored demonstration facts, not data inferred from photographs or scientific textile measurements.

Current verification tests the local implementation and actual UI output. Chromium desktop/simulated mobile is the primary browser coverage. Live deployment, physical-device camera behavior, Safari/Firefox and human acceptance remain separate checks. Historical V1 results are not claimed as V2 results.
