# Familiar Final Generator MegaPrompt Pack

## Purpose

This package is the generation brief for a fresh agentic build session. Upload this ZIP together with the companion `Familiar_Vision_Demonstrator.zip`. The companion is a previous runnable scaffold and reference implementation. It is input material only. The fresh build must inspect it, improve it, and produce the final Familiar experience.

## Required outputs from the fresh build

The fresh build must produce both files:

1. `Familiar_Final_Vercel_Deployable.zip` containing a complete root-level Vercel-ready app, all editable source, package manifests, `vercel.json`, generated 3D assets, tests, and production `dist/` output.
2. `Familiar_Final_Source_Assets.zip` containing the complete editable source, original and generated assets, GLB/GLTF files, manifests, references, prompts, context pack, tests, QA evidence, and build instructions.

The final result must be a finished vision product. A scaffold, a static collection of screens, or a procedural fabric placeholder is not a sufficient output.

## Read order

1. `handoff/GENERATION_MASTER_PROMPT.md`
2. `context/UPDATED_MASTER_AI_CONTEXT.md`
3. `asset_briefs/THREE_D_ASSET_GENERATION_BRIEF.md`
4. `handoff/PRODUCT_AND_STATE_SPEC.md`
5. `handoff/DESIGN_SYSTEM_AND_LOGO_SPEC.md`
6. `qa/SELF_REVIEW_AND_VERIFICATION_PROTOCOL.md`
7. `references/REFERENCE_INDEX.md` and `references/SKILL_REFERENCE_MAP.md`
8. The companion `Familiar_Vision_Demonstrator.zip`

## Operating rule

Do not stop after reading the prompt or after making a visual mockup. Execute the full build, inspect the real running product, run tests, verify 3D assets, and create both required ZIP outputs.
