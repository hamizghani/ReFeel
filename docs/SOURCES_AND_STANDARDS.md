# V3 sources and standards

The user's approved V3 animation and comparison changes extend the V2 photo marketplace. The attached DESIGN GUIDELINE governs the lavender palette and typography. Stitch mobile/desktop exports govern much of the marketplace composition, with layout and garment facts standardized across routes. Their unsupported confidence statistics or sensor claims are not adopted.

## Design and implementation references

- [Taste Skill](https://github.com/Leonxlnx/taste-skill), deliberate hierarchy and useful interaction detail.
- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines), controls, focus, reduced motion and responsive review.
- [Awesome Design MD](https://github.com/voltagent/awesome-design-md), marketplace design references.
- [Vite on Vercel](https://vercel.com/docs/frameworks/frontend/vite), static build and SPA routing.
- [Three.js OrbitControls](https://threejs.org/docs/pages/OrbitControls.html), interactive camera control.
- [Playwright](https://playwright.dev/docs/intro), browser interaction checks.
- [WCAG 2.1](https://www.w3.org/TR/WCAG21/), bounded automated A/AA checks with Axe; no complete conformance claim.

The numerical method and calibration limits are documented with primary papers in `docs/CLOTH_PHYSICS.md`. Photo sources are in the provenance document and manifests. Current verification evidence relates to this local release, not to the older live site. Physical-device frame rate and real tactile prediction remain separate acceptance tasks.
