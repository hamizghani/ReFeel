# Completion report template

Write a short report outside the product files containing:

- exact output filenames and sizes;
- build command and exit status;
- unit test count and result;
- browser route test count and result;
- 3D asset checks and result;
- responsive and fallback checks and result;
- ZIP integrity result;
- any material unresolved verification gap.

Do not call the work complete if a required check was skipped. State the concrete reason and the affected requirement.
