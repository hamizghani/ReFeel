# Sources and standards

Product decisions come from the supplied Familiar updated context and generation brief. The original research context is retained without introducing new business or scientific claims.

The design uses interaction principles from the supplied marketplace, guided verification and historical source references. Third-party screenshots remain references; the product uses original brand, garment and prepared-source imagery. Reference filenames alone do not establish a screen's purpose.

Applied implementation and review guidance:

- [Taste Skill](https://github.com/Leonxlnx/taste-skill): context-driven design, restrained interaction states and frontend visual review.
- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines): semantic controls, focus, source recovery, motion, imagery and responsive behavior.
- [Awesome Design MD](https://github.com/voltagent/awesome-design-md): marketplace discovery and product-detail interaction references.
- [Microsoft Playwright CLI](https://github.com/microsoft/playwright-cli): browser interaction and testing guidance. The reproducible tests use the Playwright JavaScript API.
- Vercel. (2026, August 26). [Vite on Vercel](https://vercel.com/docs/frameworks/frontend/vite). The static SPA routing configuration follows the documented root rewrite pattern.
- [WCAG 2.1](https://www.w3.org/TR/WCAG21/): automated Axe checks use A/AA rule tags. These checks are bounded automated coverage and do not constitute full human accessibility certification.

The primary verification browser is Chromium through Playwright. Rendered model and responsive page images were inspected by automated agents. No human acceptance session, physical-device session, Safari or Firefox certification was performed.
