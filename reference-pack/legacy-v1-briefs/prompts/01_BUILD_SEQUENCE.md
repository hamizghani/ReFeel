# Build sequence for the continuation agent

1. Read all handoff and context files.
2. Inspect the companion app and record reusable patterns and defects.
3. Write a short implementation ledger with exact decisions.
4. Create the design token and logo system.
5. Create and verify GLB assets before wiring them into product screens.
6. Implement the typed fixture domain and state transitions with tests first.
7. Build role gateway and marketplace.
8. Build listing, evidence, Match, and paired comparison.
9. Build seller capture, review, and publication.
10. Build commerce state.
11. Add responsive and fallback behavior.
12. Run the review and verification matrix.
13. Fix defects in impact order.
14. Build and package both ZIP outputs.
15. Inspect the ZIPs after creation and report only verified results.
